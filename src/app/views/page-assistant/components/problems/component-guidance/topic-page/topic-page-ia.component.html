To edit this topic page or to convert it to one, follow these steps:

Get current IA Structure Copy IA URLs Retrieve visits from UPD Create new topic page tree

Execute a crawl of the IA (depth of 3 or 4 recommended). This will:

  • Retrieve the subpages
  • Retrieve the depths
  • Generate a visual IA structure tree below

Copy all URLs in the IA structure to the clipboard.

Manually retrieve page visits from the UPD:

  1. Visit Custom reports page of the UPD
  2. Select data granularity: None
  3. Select a date range > Preset: Last year
  4. Select pages > Bulk Pages: Paste the copied URLs into text field
  5. Select metrics: check Visits box
  6. Scroll down and select Generate report
  7. Export the report as a CSV and save it

Upload your saved CSV file. This will:

  • Display page visits in IA structure
  • Create a new tree: you can drag pages to design
  • Suggest pages for Most requested and Doormats based on visits and levels
